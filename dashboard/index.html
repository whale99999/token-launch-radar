How implied value is computed

One function scores every row. No protocol name is special-cased, and no row is hand-picked. The page recomputes each row from the snapshot figures and checks it against the number board.json carries.

  • TVL x 0.30 — the protocol's size today, at a 0.30x multiple.
  • Growth — the seven-day TVL change, clamped to -50%…+150% and weighted 0.80, so one hot week cannot dominate and shrinkage is punished.
  • Maturity — 0.70 for a newborn protocol, rising to 1.00 after four years tracked with no token: survival earns the patience premium.
  • Chains — +4% per extra chain, capped at five: distribution across chains is worth something, but not everything.
  • Age — days from first listing to the snapshot date; an unlisted age uses 365 days.

Live-token protocols are set aside with their market caps shown as facts, not models. A protocol "records no token" in DefiLlama's record — the snapshot is not proof it has none.
